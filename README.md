# Resume_ATS (AI-Powered Resume ATS Analyzer)
 
 An AI-powered web application that analyzes resumes against specific job descriptions and provides ATS-based insights to help users improve their resumes and increase their chances of getting shortlisted.

## About the Project

The Resume ATS Analyzer was developed as part of a 3-Day Employability Enhancement Workshop conducted by MyAnatomy at Birla Institute of Applied Sciences (BIAS).
The application combines Full Stack Development and Generative AI to analyze resume content, compare it with job requirements, and provide meaningful feedback.

## Features
  
 • Resume upload and text extraction

 • Job Description analysis

 • Keyword and skill matching

 • AI-powered resume analysis using Gemini AI

 • ATS-based feedback and insights

 • Suggestions to improve resume content

 • Frontend and backend integration

 • Database integration for application data

 • User-friendly and responsive interface
